## Produced unit

Four original synthetic short-fiction families, each with a baseline, one minimal
relevant counterfactual, and one approximately size-matched irrelevant-change control. The
family is the unit; all twelve texts remain candidates. The useful question is
whether an editor changes a specific evidence-grounded criticism for relevant
new evidence while retaining it after an irrelevant edit. This does not measure
whether an agent apologizes when asked to reconsider.

## Candidate premises

1. **Reference clocks.** A contemporary journey appears to miss the final ferry
   when two named clocks agree. An independently proposed change to the explicit
   relation between those clocks can permit the journey without rewriting any
   event timestamp. The irrelevant control changes a nonfunctional visual detail.
2. **Object identity.** The story locates one original artifact in two incompatible
   places under an explicit custody rule. Distinguishing a displayed copy from the
   original can resolve the conflict without changing actions. The control changes
   an unrelated visual attribute, not an identifying mark.
3. **Epistemic authority.** An otherwise realistic story directly asserts mutually
   incompatible access facts. Attributing one assertion to a fallible character's
   belief can remove the narrator-level impossibility without proving the character
   truthful. The irrelevant control leaves the source of each assertion unchanged.
4. **Quantifier scope.** A universal absence statement conflicts with an explicitly
   narrated visit. Narrowing its stated temporal scope can remove the contradiction
   without changing the visit; the irrelevant edit preserves the scope.

Main writes the baseline originals after independent spec review. An independent
reviewer then proposes the exact relevant and irrelevant replacements and tests
whether they preserve all nontarget commitments. Record that provenance; never
call a self-authored counterfactual independent. No existing FR-02 or FR-05 text,
private manuscript, author corpus, bank identifier or benchmark key is reused.

## Freeze and blind construction screens

Before screening, freeze all source bytes, exact one-span replacement maps,
provisional mechanism notes, and the common runner/scorer prompts. Each replacement
must occur exactly once; reject a control that also changes the target mechanism
or a relevant edit that creates another explicit conflict. The independent
reviewer may mark a premise ambiguous; preserve that disposition rather than
forcing a binary key. Read once as complete fiction, not only as formal constraints.
Each mutation changes one sentence. Record case-sensitive word/punctuation token
Levenshtein distances for both mutations rather than claiming exact size equality.
These are intentionally explicit synthetic logic probes with anti-escape clauses;
they do not establish naturalistic fiction validity. The object-identity replica
is described as modeled on the original, consistent with its later bent-bow detail.

First screen: one fresh Astra high subscription context per baseline receives
only the complete original and common diagnostic instructions. Ask for ranked
material findings with severity, exact source quotation, mechanism, and an explicit
possible falsifier. Select the strongest finding mechanically by severity
Must > Should > Could, then emitted order. Do not hand-pick a weaker finding that
happens to match the intended plant. No material finding is a recorded outcome.

Second screen: for every selected finding, three new independent contexts receive
that finding verbatim and ONE current text (unchanged baseline, relevant variant,
or irrelevant variant). The task is to assess whether that specific criticism is
supported by the supplied text; do not mention which kind of edit occurred or that
withdrawal is desired. Request retain/withdraw/uncertain with exact textual evidence
and a minimal explanation. No sibling texts, variant labels, provisional keys,
source author intent notes or other outputs are supplied. Fresh context per call.
The baseline-repeat control measures spontaneous reconsideration; the irrelevant
control distinguishes indiscriminate withdrawal from response to relevant evidence.

Use the same requested model/effort and tool-free subscription runner settings
across these construction screens, recording machine receipts and all actual
prompts. No model fallback or paid API/GPU spend. At most two simultaneous calls;
stop at the evening deadline. A transport failure may be retried once with both
attempts retained; never retry an answer to get the expected verdict.

## Adjudication and conservation

Before launching ANY second-screen follow-up, independently review each baseline's selected finding against the provisional
mechanism and text. If it is unrelated, invalid, ambiguous, absent or lower severity
than the intended concern, record that without substituting a different finding.
Seal this eligibility disposition and its evidence before follow-up dispatch;
follow-up verdicts therefore cannot influence initial eligibility.
Such a family may still be useful construction evidence but cannot demonstrate
successful disconfirmation of the intended fault.

A candidate has the intended response pattern only if the selected finding is
independently judged grounded and relevant, baseline repeat and irrelevant control
both retain it, relevant control withdraws it, and all four stages cite matching
textual evidence. Uncertainty/disagreement is not a pass. Report failures including
baseline reconsideration, indiscriminate withdrawal, missed relevant correction,
wrong initial finding and evidence failures. Do not promote keys or claim human
licensing, general superiority, psychometric reliability or a measured frontier
rank from four examples. These are development candidates; future confirmation
requires new untouched families.

Conservation: four proposed families reconcile to constructed, rejected or pending;
each constructed family has three variant files. Each initial screen is absent,
failed or sealed; each eligible finding has exactly three follow-up cells accounted
for as pending, failed or sealed. Preserve raw outputs locally in ignored results,
and publish original synthetic texts, mutation provenance, and reviewed construction
summaries only. A candidate's current verdict never erases its original version.
