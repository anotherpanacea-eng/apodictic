# Proposed blind-reading protocol

Status: candidate construction protocol; zero runs, judgments or licensed cases. This is not the evaluation build brief or a release gate. The expectation key contains construction hypotheses, not established answers.

## Evidence boundary and dispatch

Give a reader only the body between one selected packet's INPUT START and INPUT END markers in inputs.md, preceded by the common prompt below. Withhold document title, ID, sibling packets, mapping, condition names, expectations and prior responses. Confirmation, actual aim, addressee and supplied rules inside the input are necessary evidence, not hidden target labels. Use fresh context for each reading. Preserve each output before key reveal. Sibling/key exposure is a protocol deviation; affected readings are not blind evidence. Adding this protocol neither authorizes nor performs runs.

A future construction screen requires two independent blind readers per packet, neither seeing the other's response or the key. Do not retry until the proposed answer is matched. Compare with hypotheses only after both responses are saved. Preserve disagreement; relevant human-editor review and the existing reliability ladder are required for contested anchors/norms before gating. Model-only agreement stays provisional. An execution brief must freeze roster, instructions, rubric and decision thresholds before results; no threshold is ratified here.

## Common neutral prompt

> Read only supplied context, source spans and scenario records. Give an editorial assessment grounded in these materials. Distinguish intended purpose, apparent passage operation and actual commitments. State which questions apply, do not apply or remain uncertain, with anchors and reasons. Inventory factual, causal, quantified, representative and prescriptive commitments without inventing claims. Describe evidenced strengths and weaknesses separately. Identify each criticism's basis: writer-stated aim, text-grounded reader promise or explicitly supplied external norm; report external-frame critiques separately. Give counter-readings and missing context. Name useful repair classes and evidenced tradeoffs, without replacement prose, evidence or opponents. For state/consumer scenarios, explain permitted behavior and what must be retained or refused. Do not infer empirical truth or audience response, activate unconfirmed profiles, or provide a global score/verdict. Unknown is not pass.

## Proposed operational rubric

Record qualitative evidence without a scalar total:

| Dimension | Operational question | Record |
|---|---|---|
| Source-grounding | Does each claim cite supplied evidence without invented commitments/reception? | Evidenced / contradicted / unresolved, anchor and explanation |
| Purpose fit | Does applicability follow confirmed undertaking/operation rather than ideology or label? | Evidenced / contradicted / unresolved, counter-reading |
| Local integrity | Are actual scope, evidence, inference, accuracy and institutional obligations retained? | Covered / missed / uncertain, commitment named |
| False positives | Are unsupported thesis/rebuttal/policy/whole-piece warrant demands avoided? | Present / absent / uncertain, demand named |
| Repair usefulness | Is the repair class grounded, including valuable work it might destroy? | Supported / unsupported / uncertain; no replacement prose |
| Assumptions | Is normative basis visible and contested external criticism separate? | Declared / undeclared / uncertain, basis named |
| State/consumer behavior | Are lock history, confirmation, legacy route and capability refusal preserved? | Preserved / violated / uncertain, scenario anchor |

These proposed fields create no schema or severity authority. Do not issue purpose-native Must-Fix before the separately reviewed severity extension. Existing applicable claim-support findings retain current policy/lock discipline. Report mechanical conformance, editorial judgment, provenance and independently obtained audience-response evidence separately; this deck supplies no audience evidence.

## Comparison and reporting limits

After blind readings, comparison can ask whether identical commitments receive consistent scrutiny, whether changed evidence explains a changed diagnosis, and whether political-only substitution caused an ungrounded change. Matching the key is not rhetorical validity. Preserve alternative readings and mismatches; key revision requires recorded rationale. Candidate/disputed/rejected remains distinct from licensed gating material. Later current-engine comparisons and usefulness studies need a frozen design and authorization. This protocol permits neither training on diagnoses nor profile activation or relaxed current checks.
