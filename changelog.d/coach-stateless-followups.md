### Revision Coach — Learning Mode follow-ups

The coaching protocol's no-diagnostic rule now matches `/coach`: an argument-track project with only
`Argument_State.md` is coached from it, and Learning Mode and an accepted state-less Stuck-Point
run are no longer sent to `/start`. The state-less run now writes nothing at all (no session plan,
archive, log or `README.md` row), as its changelog entry in v2.16.0 promised.
