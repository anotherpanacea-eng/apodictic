### Revision Coach — Learning Mode

`/coach learn` adds a craft syllabus built from the existing audit files: 15 fiction lessons in seven units plus a four-lesson argument track. Each session teaches one concept from its audit's opening section, gives one firewall-passing exercise, and names the audit that tests the skill on the writer's own pages. Progress lives in `Syllabus_Progress.md`; a lesson clears when its finding reaches `revised` or the audit finds nothing to flag. Works without a diagnosis. The syllabus file loads only in this mode, so normal runs are unchanged.
