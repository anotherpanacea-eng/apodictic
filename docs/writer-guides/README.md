# Writer guides

Short, plain-language companions to the level-setting research briefs in `docs/`. The briefs were written for the people who designed APODICTIC's audits and run to 10–40 KB each. Each guide here is a page or less for writers. It keeps the brief's one-line rule word for word, then says what the idea looks like in your draft, how it usually goes wrong, and when an apparent fault is a deliberate choice.

These cover the 11 briefs that the `/coach` Learning Mode lessons draw on. The briefs themselves are unchanged and remain the full source.
