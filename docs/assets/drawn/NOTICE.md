# Drawn diagrams: notice

The files in this folder are generated from `*.json` sources by the fleet `pele-teaching-animation` skill. The README's Mermaid chart stays the source of truth for the route; these drawings illustrate it.

They contain only generated SVG path data. They were laid out at authoring time with Pele 1.10.0 (MIT, Obsidian) and lettered with `hersheytext` 2.0.0 (MIT, James T), which carries A. V. Hershey's 1967 public-domain letterforms. Neither library ships in these files or in the plugin.
